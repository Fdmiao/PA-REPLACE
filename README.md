# PA 替代功能对比项目

> 天融信 NGFW × Palo Alto NGFW 功能对比（纯技术调研，无实测） · 面向港澳市场 PA 替代场景

## 项目定位

在 **产品功能层面** 对天融信 NGFW 与 Palo Alto NGFW（PAN-OS）两条在售产品线做系统化对比，为 PA 替代选型与迁移提供证据化的功能对照与交付物。

- 对比定位：纯技术调研，不涉及性能 / 吞吐 / 并发 / 延迟
- 对比对象：双方在售产品线功能全集（不以单一型号锚定）
- 天融信侧版本基线：《天融信防火墙系统一本通》CHM 所载版本 + 官网核对
- PA 侧版本基线：PAN-OS 12.1（12.1 新增特性以英文文档为准，中文对照以 11.1 & later 手册为准）
- 动作保证：双方全授权；本次不做真机实测，无法确证项标注"待验证"
- 场景背景：港澳市场关注 Facebook / WhatsApp / TikTok / Threads 等国际应用识别、英文界面、配置迁移工具
