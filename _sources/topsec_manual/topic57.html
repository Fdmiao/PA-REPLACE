资源管理

配置资源对象的具体操作步骤如下。

步骤1选择 网络管理 > SSLVPN > 资源管理，激活“资源管理”页签。

² NGFW仅支持全网接入的用户访问资源模式，不支持其他模式。

点击『添加』，弹出“添加资源管理”窗口，如下图所示。

在设置自定义资源时，各项参数的具体说明如下表所示。

参数

说明

名称

必填项，管理员可根据实际需要命名资源名称。中文最大输入长度为21，英文最大输入长度为63。

描述

输入资源的描述信息。中文最大输入长度为42，英文最大输入长度为127。

图标

在下拉框中选择已添加的图标，用于标识资源。

URL

必填项，指定该资源的访问地址，支持https，http或ftp格式。

域名

用户使用域名方式访问资源服务器。

说明：

1）“域名”和“IP地址”不能同时为空。

2）如果选择只填写域名，则需要在NGFW中配合设置DNS域名服务器，请参见 本机域名解析。

IP

输入资源服务器的IP地址。

说明：

1）“域名”和“IP地址”不能同时为空。

2）如果域名和IP地址同时设定，表示手动指定域名和IP对应关系。

网络掩码

输入IP地址对应的子网掩码（常用的网络掩码为24/32位）。

协议类型

在下拉框中选择用户访问使用的协议类型，可选项：IP、ICMP、TCP和UDP协议；缺省值;IP。

说明：

如果是FTP资源建议选择IP协议。
步骤2点击【确定】按钮，完成自定义资源的添加。
