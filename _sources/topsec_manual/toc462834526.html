认证服务器

用户经过NGFW访问网络资源前，首先需通过NGFW的认证，同时还会检查用户的属性，如用户账号是否可用、账号过期时间、用户访问策略等信息，只有认证和安全策略都放行的用户，才可访问其被授权的网络资源。为提升用户认证效率和对第三方认证服务器的支持，用户分为本地用户和外部用户映射。

NGFW本身可以认证服务器接受本地用户的认证请求，验证用户的合法性，也可以向外部认证服务器转发用户的认证请求，由外部认证服务器验证用户是否合法。NGFW支持的外部认证协议包括如下三种：

lRADIUS：Remote Authentication Dial In User Service，远程用户拨号认证系统，是目前应用最广泛的AAA协议。RADIUS协议认证机制灵活，可以采用PAP、CHAP或者Unix登录认证等多种方式；另外，RADIUS也是一种可扩展的协议，它进行的全部工作都是基于Attribute-Length-Value的向量进行的。

lLDAP： Lightweight Directory Access Protocol，LDAP是轻量目录访问协议，是基于X.500标准的协议，内容简单并可根据需要定制。

lTACACS：Terminal Access Controller Access-Control System，终端访问控制器访问控制系统。该协议允许远程访问服务器传送用户登录密码给认证服务器，由认证服务器决定该用户是否可以登录系统。
